# 本地视频翻译

使用本机 AI，为浏览器视频实时转写并翻译字幕，无需云端 API。

[English](README.md) · [安装说明](docs/INSTALL.md)

插件读取当前 Chrome 标签页的声音，经本机语音识别和翻译模型生成字幕。视频无需自带字幕。

当前版本的界面和译文为简体中文；原语言可以自动识别或手动选择，尚未加入目标语言选择。项目仍是 Windows 实验版本，仓库提供源码，模型、运行程序及 Python 环境需要另外准备。

## 能做什么

- Nemotron 流式识别，Hy-MT2 本地翻译；也保留 Qwen 兼容模式。
- 支持多种原语言、双语显示、调整字号和拖动字幕。
- 在支持的播放器中处理暂停、恢复、进度跳转和视频切换。
- 默认不保存录音和字幕，不调用云端识别或翻译 API。
- 一次翻译一个标签页，通过本地控制台加载、释放模型。

## 安装与使用

安装依赖、模型、推理运行程序，并把 `config.example.json` 复制为 `config.json`。具体目录和命令见[安装说明](docs/INSTALL.md)。不需要使用开发者原电脑的路径。

准备完成后：

1. 双击项目内的“启动本地视频翻译.vbs”，等待模型就绪。
2. 在 `chrome://extensions` 开启开发者模式，加载本项目的 `extension` 文件夹。
3. 在控制台复制本机连接码，粘贴到插件设置并保存。
4. 打开视频页面，在插件中开始翻译，再播放视频。

快捷键为 `Alt + Shift + T`。关闭控制台网页不会退出后台；请使用控制台的“退出服务”。

## 当前边界

实时模式开放 17 种原语言，兼容模式开放 23 种；详细列表见英文首页。已实际试用英、法、西、意，未逐一验证所有语言。

字幕会随新增内容修正。专有名词、数字、口音、音乐和多人说话仍可能导致错误。新版长时间连续运行和较长暂停恢复尚未完成验证；也没有在一台全新电脑上完成安装验证。

本仓库不包含模型、运行环境、本机连接码、浏览器数据或开发录音。首次下载模型和播放网络视频仍需要网络。其他组件保留各自许可证；项目自身的源码许可证尚未选择。
