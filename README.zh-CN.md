# 本地视频翻译

使用本机 AI，为浏览器视频实时转写并翻译字幕，无需云端 API。

[English](README.md) | **简体中文**

[安装指南](docs/INSTALL.md)

插件读取 Chrome 标签页的声音，在本机 NVIDIA 显卡上识别语音，并将翻译后的字幕显示在视频页面上。视频无需自带字幕。当前版本的界面和译文为简体中文，尚未加入其他目标语言的选择功能。

**项目状态：Windows 实验版本。** 仓库提供源码，暂不提供可直接运行的安装包。模型和推理运行程序需要单独下载，尚未在一台全新电脑上完成安装验证。

## 功能

- 通过 Manifest V3 插件直接采集标签页音频，无需麦克风。
- 使用 NVIDIA Nemotron 3.5 ASR 在本机进行流式语音识别。
- 通过 llama.cpp 运行 Hy-MT2 1.8B，在本机翻译字幕。
- 自动识别原语言，也可以手动选择。
- 支持拖动字幕、调整字号、显示原文，以及在播放器允许的情况下全屏显示字幕。
- 处理暂停、恢复、进度跳转和视频切换，一次翻译一个标签页。
- 提供可选的 Qwen3-ASR 兼容模式，支持更多原语言。
- 通过本地控制台加载、释放模型和切换识别模式。

语音识别和翻译均在本机进行。播放视频的网站仍会正常联网，首次下载模型和运行程序也需要网络。

## 运行要求

- Windows 64 位系统和 Python 3.12。
- Chrome 116 或更新版本，允许加载解压后的扩展程序。
- NVIDIA 显卡，以及与所选 CUDA 运行程序兼容的驱动。
- 开发时使用的硬件：RTX 5060 8 GB 显存、32 GB 内存。其他硬件尚未经过系统验证。

## 安装与使用

安装依赖、模型、推理运行程序，并把 `config.example.json` 复制为 `config.json`。具体目录和命令见[安装说明](docs/INSTALL.md)。不需要使用开发者原电脑的路径。

准备完成后：

1. 双击 `启动本地视频翻译.vbs`，或在项目目录的 PowerShell 中运行 `.\.venv\Scripts\python.exe run.py`。
2. 等待本地控制台显示模型已就绪。
3. 打开 `chrome://extensions`，开启开发者模式，点击“加载已解压的扩展程序”，选择项目中的 `extension` 文件夹。
4. 从本地控制台复制连接码，在插件的连接设置中粘贴并保存。
5. 打开视频页面，在插件中开始翻译，再播放视频。

快捷键 `Alt + Shift + T` 可以开始或停止当前标签页的翻译。更换原语言或识别模式前，请先停止翻译。关闭控制台网页不会退出后台；请使用控制台的退出按钮释放模型并关闭服务。

## 原语言支持

| 模式 | 可选择的原语言 |
| --- | --- |
| 流式模式 / Nemotron | 英语、西班牙语、意大利语、法语、德语、葡萄牙语、日语、韩语、俄语、阿拉伯语、印地语、越南语、土耳其语、荷兰语、波兰语、捷克语、中文 |
| 兼容模式 / Qwen | 以上语言，以及泰语、印度尼西亚语、马来语、菲律宾语、波斯语、粤语 |

这些选项来自当前配置的模型组合，不代表每种语言的效果都经过验证。目前实际试用过英语、法语、西班牙语和意大利语。自动识别的语言范围受所选识别模式限制。

## 工作原理

```text
Chrome 标签页音频
    -> tabCapture + AudioWorklet（16 kHz PCM 音频）
    -> 带连接认证的本机 WebSocket
    -> Nemotron 流式识别 / 可选 Qwen 识别
    -> 通过 llama.cpp 运行 Hy-MT2 翻译
    -> 在页面上显示字幕
```

后台服务、翻译运行程序和流式识别运行程序分别监听本机回环地址的 `18765`、`18766`、`18767` 端口。请保持这些端口可用；插件目前使用 `18765` 端口连接后台。

## 隐私与本地文件

- 只采集你主动开始翻译的标签页，视频原声仍可正常播放。
- 音频保存在内存中，发送至本机回环服务。默认不保存录音和字幕。
- 本机连接码在运行时生成，保存到 `runtime/access.json`，配对后也会保存在插件的本地存储中。
- 仓库不包含模型、运行环境、连接码、本机配置、浏览器数据、日志或开发录音。
- `.gitignore` 只控制 Git 跟踪的文件，不会替你过滤通过网页手动上传的文件。

## 当前限制

随着新的语音内容到来，字幕可能继续修正；一句话尚未说完时，也可能更新前面已显示的文字。专有名词、数字、口音、多人同时说话和背景音乐都可能导致识别或翻译错误。流式模式并不保证在所有场景下都比 Qwen 更准确。

暂不支持受保护媒体、浏览器内部页面和画中画字幕叠加。部分跨域或封闭播放器的播放事件可能无法检测；停止后重新开始翻译可以清空本次上下文。

当前流式版本的长时间连续运行和较长暂停后的恢复尚未完成充分验证，不保证固定的准确率或字幕延迟。
